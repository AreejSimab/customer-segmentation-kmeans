# Data

The raw file is not stored in this repository. Download **Mall Customer Segmentation Data** from Kaggle:
https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python

Save it in this folder as `Mall_Customers.csv`, so the notebook can read `data/Mall_Customers.csv`.

| Column | Description |
|---|---|
| CustomerID | Unique ID of the customer (not used) |
| Gender | Male or Female |
| Age | Age in years |
| Annual Income (k$) | Yearly income in thousands of dollars |
| Spending Score (1-100) | Score given by the mall from customer spending |

Check the dataset's licence on Kaggle before reusing it.
